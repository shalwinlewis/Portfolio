# 🌐 Personal Portfolio Website

This repository contains my **personal portfolio website**, designed to showcase my background, skills, and learning journey as an **Aspiring Data Analyst and AI enthusiast**.

The portfolio highlights my academic background, technical skills, and readiness to work on real-world data problems, while maintaining a clean and modern user experience.

---

## 🎨 Design Overview

- **Dark Theme** with neon green accents for a modern, professional look.  
- **Minimal & Clean UI** focused on clarity and readability.  
- **Fully Responsive** across desktop, tablet, and mobile devices.  
- **Smooth Animations & Transitions** for an engaging browsing experience.  

---

## 🚀 Website Features

- **Hero Section**  
  Dynamic typing animation showcasing roles and interests  

- **About Me**  
  A brief professional introduction highlighting my interests and background  

- **Skills Section**  
  Categorized display of technical and analytical skills  

- **Projects Section**  
  Placeholder section prepared for upcoming data analytics and ML projects  

- **Education**  
  Academic background and relevant coursework  

- **Resume**  
  Direct download link to my latest resume (PDF)  

- **Contact**  
  Quick access to GitHub, LinkedIn, LeetCode, and email  

---

## 🛠️ Technologies Used

- **HTML5** – Semantic and accessible markup  
- **CSS3** – Custom styling, animations, and responsive layouts  
- **JavaScript** – Interactivity, scroll animations, and dynamic elements  
- **Google Fonts** – Inter font family for clean typography
